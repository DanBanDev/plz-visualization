# PLZ5 Visualizer

Web application for visualizing German postal code areas.

## Features

- Upload CSV files containing postal codes and values
- Color based visualization of PLZ5 areas
- Group visualization
- Heatmap visualization
- User based visualizations

## Technologies

Frontend:
- Angular
- Angular Material
- OpenLayers

Backend:
- ASP.NET Core Web API
- Entity Framework Core

Database:
- PostgreSQL
- PostGIS
